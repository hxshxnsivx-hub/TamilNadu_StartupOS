# Vanigam logic arena: weighted flags

**Date:** 2026-10-17
**Status:** draft (for owner review, then folding into `docs/specs/TASKS.md` and the design documents)

## What this is

Ten agents in two teams searched the build plan (`docs/specs/TASKS.md`) and the code behind it for problems the plan and design do not already list: logic flaws, missing logic, missing optimisations, and missing structural or functional parts. Every flag has evidence (a file and line, a data key, or a test run).

- **Team A (sequential):** one agent per phase, district by district (23 districts).
- **Team B (relational):** five agents walking 8 tasks each, always to the most related unvisited task (explicit reference 3, shared code file 2, shared decision 1), so problems that only show across tasks surface.

They raised 269 flags; duplicates found independently by several agents were merged into **213 distinct problems** (40 confirmed by more than one agent).

**Weight** = 50% impact (1–5) + 30% reach (1–5) + 20% confidence (1–3), scaled to 100. A merged problem takes the highest weight among its flags. Every stack option was required to be free and offline; a paid option appears only where it is ruled out for cost.

The live dashboard of the run is the Vanigam Logic Arena artifact.
